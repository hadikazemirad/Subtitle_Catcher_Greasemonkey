# Subtitle Catcher — Greasemonkey 2.1.17

## تغییرات این نسخه
- تبدیل زیرنویس WebVTT با پسوند `.vtt` به SRT واقعی، همراه با شماره‌گذاری و تبدیل زمان‌ها.
- خروجی ASS برای نگه‌داشتن بخشی از ظاهر زیرنویس: رنگ و پس‌زمینه، نام و اندازه فونت، ضخامت/حالت مورب، تراز و تنظیمات موقعیت VTT.
- دکمه بررسی استایل برای نمایش رنگ، پس‌زمینه، فونت، اندازه و تنظیمات جایگاه تعریف‌شده در فایل VTT.
- تبدیل فونت WOFF نسخه 1 به TTF یا OTF با بازسازی جدول‌های فونت.

## نکته‌های مهم
- SRT استاندارد اطلاعات رنگ و جایگاه را نگه نمی‌دارد؛ برای حفظ استایل از خروجی ASS استفاده کنید.
- تبدیل فونت در این نسخه فقط برای **WOFF1** است. فایل‌های WOFF2، فونت‌های رمزگذاری‌شده/محافظت‌شده و فونت‌هایی که نشانی مستقیم ندارند تبدیل نمی‌شوند.
- در خروجی ASS، استایل‌های عمومی `::cue` و تنظیمات رایج جایگاه VTT نگاشت می‌شوند؛ همهٔ CSSهای پیچیده، استایل‌های اختصاصی هر کلاس و ویژگی‌های خاص هر سایت تضمین‌شده نیستند.
- دکمه‌های تبدیل زیرنویس فعلاً برای فایل‌هایی نمایش داده می‌شوند که نشانی آن‌ها پسوند `.vtt` دارد.
- تبدیل‌ها داخل مرورگر انجام می‌شوند و فایل منبع باید از طریق نشست/دسترسی مرورگر قابل دریافت باشد.

## نصب یا به‌روزرسانی
1. در Greasemonkey نسخه قبلی Subtitle Catcher را غیرفعال یا حذف کنید.
2. فایل `Subtitle_Catcher_Greasemonkey.user.js` را باز کنید و نصب را تأیید کنید.
3. صفحه فیلم را دوباره بارگذاری کنید و دکمه شناور را بزنید.
4. برای زیرنویس VTT از «تبدیل به SRT» یا «تبدیل با حفظ استایل (ASS)» استفاده کنید.
5. برای فونت WOFF از «تبدیل WOFF به TTF/OTF» استفاده کنید.
